# Security policy

Please report suspected security or privacy issues privately to [contact@qedartifacts.org](mailto:contact@qedartifacts.org). Do not disclose sensitive details in a public issue, discussion, pull request, or commit.

Include the affected repository or service, a concise description, reproduction information where safe, and any known impact. QED-AI will review the report and coordinate an appropriate response. This policy does not establish a vulnerability-reward program or authorize disruptive testing.
