# Public publication policy

GitHub is QED-AI's transparent public publication and software-development plane.
It is not the system of record for confidential operations.

## Release boundary

Only unrestricted material may enter a public repository. Material prepared in
Microsoft 365 crosses into GitHub through a deliberate, human-reviewed release.
The public copy must be self-contained, stripped of confidential metadata, and
appropriate for perpetual worldwide access and repository history.

The permitted flow is one way:

`controlled working record -> reviewed public derivative -> public repository`

Public edits do not silently overwrite the controlled record. If a public change
affects an authoritative internal record, it is reconciled through the applicable
Microsoft 365 record process.

## Information classes

- **Public:** GitHub and public websites are permitted.
- **Internal:** Microsoft 365 only unless formally released.
- **Confidential:** Board-controlled Microsoft 365 areas only.
- **Restricted source:** controlled evidence storage; publish only lawful metadata,
  quotations, or derivatives.
- **Secret:** an approved secret store; never documents, repositories, or source
  files.

The machine-readable public registry is the authoritative public statement of
these classes and domain boundaries.
